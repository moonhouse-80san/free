# free — 문하우스 자료 보관용 저장소

문하우스(moonhouse.co.kr) 유틸리티 게시물에 올려 둔 첨부 파일을 모아 두는 저장소입니다. 소스 코드가 아니라 **실행 파일·압축본·동영상**만 있습니다.

> 이 저장소는 **약 500MB**로 커서 `git clone`이 실패(HTTP 413)할 수 있습니다. 아래처럼 **필요한 파일만 하나씩 내려받으세요.**

## 내려받는 방법

1. 아래 표에서 파일 이름을 눌러 GitHub 파일 화면을 엽니다.
2. 화면 오른쪽 위의 **Download** 아이콘(↓)을 누릅니다.
3. 또는 파일 주소 끝에 `?raw=true`를 붙이면 바로 내려받힙니다.
   예) `https://github.com/moonhouse-80san/free/raw/master/ALSee69.exe`

## 주의 사항

- 실행 파일을 내려받아 설치할 때는 **Windows SmartScreen·백신 경고**가 뜰 수 있습니다. 출처가 확실한 파일인지 확인한 뒤 실행하세요.
- `DisableWindowsDefender.exe` 처럼 보안 기능을 끄는 도구는 PC를 위험하게 만들 수 있습니다. 꼭 필요할 때만, 쓰고 나면 다시 켜 두세요.
- 동영상 파일은 개인 촬영본입니다. 주소를 아는 사람은 누구나 내려받을 수 있으니 공개되면 안 되는 영상은 올리지 마세요.
- VideoAutoClick의 소스와 설치본은 별도 저장소 `moonhouse-80san/video_autoclick-installer`에도 있습니다.
- 원본 게시물과 설명은 문하우스 사이트의 **Data > 유틸리티** 게시판에서 확인하세요. https://moonhouse.co.kr
